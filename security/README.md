# Sécurité

Ce dossier contiendra les règles et configurations versionnées :

- détection de secrets ;
- analyse des dépendances et du code ;
- scan des images ;
- politiques Kubernetes ;
- DAST ;
- critères de blocage et gestion documentée des exceptions.

Un résultat de scan n'est pas automatiquement un risque accepté ou refusé. Les
seuils, faux positifs, responsables et délais de correction devront être définis.
