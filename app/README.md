# Workload

Ce dossier accueillera l'application choisie plus tard.

Le contrat minimal attendu sera documenté avant l'intégration :

- commande de build et de test ;
- artefact produit ;
- port d'écoute ;
- endpoint de santé ;
- variables d'environnement ;
- méthode de construction de l'image ;
- dépendances externes et secrets nécessaires.

Tant que ce contrat n'existe pas, les étapes CI de build, SCA, image, DAST et
déploiement restent volontairement en attente.
